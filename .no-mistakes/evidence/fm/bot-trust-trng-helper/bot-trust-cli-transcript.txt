# 1. Agent-facing usage guidance (help output)
usage: bin/fm-bot-trust.sh [-h] [--explain] [mode] [input]

OS-backed secure randomness for explicit probability decisions.

positional arguments:
  mode        probability (default), select, or tree
  input

options:
  -h, --help  show this help message and exit
  --explain   print a human-readable explanation after the stable result

Examples: bin/fm-bot-trust.sh '70 %'; bin/fm-bot-trust.sh select outcomes.md;
printf '1 | yes\n3 | no\n' | bin/fm-bot-trust.sh select -
